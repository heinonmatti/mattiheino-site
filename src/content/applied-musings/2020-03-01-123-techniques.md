Most advice about changing your behaviour collapses into a single instruction:
*just be more disciplined*. That is not advice, it is a description of the problem.

What follows is a long menu &ndash; over a hundred concrete techniques &ndash;
because no single trick works for everyone, and the same person needs different
tricks on different days. Treat it as a buffet, not a prescription. Pick one.
Try it for a week. Keep it if it helps, drop it if it does not.

The point is not to do all of them. The point is to have somewhere to look when
willpower runs out, which it always does.
